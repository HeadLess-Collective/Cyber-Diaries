1. التحليل وتصميم التجربة أكتوبر 2026

  • إصدار مواصفة المتطلبات SRS v0.1 ورحلة المستخدم
  • حسم الاستضافة مبكرًا (OI-007) وتثبيت العضو الـ 13 (OI-013)
  • Gate 01: توقيع القيود الخمسة (CN-015..019)

2. المحتوى والقصة والأخلاقيات نوفمبر 2026

  • تسليم سيناريو SQL Injection بصيغة JSON/MD خام
  • كتابة الشرح والمشاهد ومرجع العالم (World Bible)
  • تقديم ملف الأخلاقيات والموافقة للجامعة مبكرًا (OI-001/004)

3. الهيكل الأساسي وعقود API ديسمبر 2026

  • تجميد عقود Swagger/OpenAPI في الأسبوع الأول (API-First)
  • بناء الخلفية .NET 10 Modular Monolith وقاعدة PostgreSQL 16
  • بناء الواجهة Next.js 14 بدعم RTL ولوحة المسارين

4. التجارب الحرجة وعزل المعمل يناير 2027

  • فصل خدمة المعمل بـ Docker وعامل التنظيف الآلي (Reaper)
  • دمج الأدوات الحقيقية (ttyd, Monaco, Adminer, curl)
  • Gate 02: اجتياز اختبار العزل (IM-006) أو تفعيل Plan B

5. النموذج التجريبي (v0.1 Pilot) فبراير 2027

  • تكامل حلقة Injection بالأدوار الـ 3 (Red / Blue / Dev)
  • تشغيل التحقق الآلي الخادمي ومحرر اليوميات
  • توثيق الساعات الفعلية للمكونات الـ 4 كشرط اكتمال (DoD)

6. القياس مع المستخدمين مارس 2027

  • Gate 03: تفعيل موافقة الأخلاقيات (أو Dogfooding داخلي)
  • تجربة 5–10 طلاب وقياس زمن الإتمام ومقياس SUS
  • Gate 04: حساب الكلفة وإعلان عدد الفئات مع المشرفين

7. التعميم المشروط (v0.2 Scale) أبريل – منتصف مايو 2027

  • إضافة الفئات الجديدة المقررة عبر لوحة Admin CMS بلا كود
  • إعادة استخدام قالب حاويات المعمل بوفر 30%–40%
  • أو التحول لتدعيم حلقة الحقن إذا ظهرت عيوب حرجة بالمرحلة 6

8. نافذة التثبيت وضمان الجودة أواخر مايو 2027 (أسبوعان)

  • تجميد كودي تام (Code Freeze) وحظر أي ميزات جديدة
  • إصلاح العلل وضبط الأداء (<500ms API / <90s Lab)
  • اختبار تزامن 10 متعلمين واستكمال مسودات الأدلة الأربعة

9. التوثيق والدراسة والمناقشة (v1.0) يونيو – يوليو 2027

  • الدراسة التقييمية الموسعة (n ≥ 10) ولوحة الصدارة الاختيارية
  • Gate 05: تجميد القوالب قبل التسليم بأسبوعين (منتصف يونيو)
  • إصدار الأدلة الأربعة والورقة البحثية والمناقشة في 07-2027
